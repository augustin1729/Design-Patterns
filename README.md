# System Design & Architecture

This repository serves as a comprehensive collection of notes, code examples, and implementations related to System Design, Software Architecture, and best coding practices.

## Repository Structure

Currently, the repository is organized into the following main areas:

- **Design patterns/**: Contains practical examples and explanations for various software design patterns. 
  - *Lesson-1/*: Introductory examples (like the SimUDuck problem) demonstrating the need for patterns like the Strategy Pattern.

*(More topics such as High-Level Design, Low-Level Design, and Architectural Patterns will be added here as the repository grows.)*

## Purpose

The goal of this repository is to document learnings and provide hands-on examples (primarily utilizing C#) for building robust, scalable, and maintainable software systems.
